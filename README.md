# Lelelilo Tetris

Falling blocks in a pencil sketchbook. Every line you clear draws more of the page; finish the drawing and the
page turns.

**Play: https://lelelilo-studios.github.io/lelelilo-tetris-web/**

It needs a browser with WebGPU: Chrome or Edge on a computer or an Android phone, or Safari 26 and later.

This repository holds only the published build of the game. A game by [lelelilo.com](https://lelelilo.com/?ref=lelelilo-tetris).
